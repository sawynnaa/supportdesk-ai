## 实现与计划表述的差异

这些差异不影响本地模拟闭环，但对外介绍时需要说清楚：

- **NestJS** 用于进程启动和静态资源挂载。HTTP API、鉴权与流式响应在 `apps/api/src/http.ts` 的 Express 路由上，没有按 `auth/` `tickets/` 拆 Nest 模块。
- **Prisma** 在配置了 `DATABASE_URL` 时负责连接和事务；登录查找用户用了 Prisma Client。复合外键、CHECK、部分唯一索引、向量检索仍以 SQL migration 和绑定参数查询为准。
- **真实模型** 只是兼容 chat/completions 与 embeddings 的可选适配器，默认关闭。模板答复是资料摘录加固定句式。
- **GitHub Actions** 与 Compose 是可复现配置，不是已经跑过的线上结果。

下一步若继续按计划收尾，优先顺序是：公开仓库并让 CI 真正跑一次、本机 Compose 冒烟、真实模型一次受控评测、试用记录。截图和录屏仍等需要展示时再补。
