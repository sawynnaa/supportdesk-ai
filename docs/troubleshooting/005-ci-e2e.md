# 真实修复：CI 上 Playwright 在 API 未就绪时登录失败

GitHub Actions 的 `validate` 在 `pnpm test:e2e` 失败：5 条里 2 条挂掉。lint、typecheck、PGlite 测试、PostgreSQL 集成测试和 build 均已通过。

第一条登录停在 `/login`，页面提示 `Unexpected end of JSON input`。原因是 Playwright 只等 Vite 的 5173 端口，`pnpm dev` 里 API 还在执行种子数据和监听 3001；此时代理返回空响应，前端 `response.json()` 直接抛错。

最后一条「模拟生成失败」其实已经把消息标成「生成失败」，但发送结束后会 `refresh()` 当前会话，`select` 无条件清空 `error`，`role="alert"` 随即消失，断言超时。

修改：E2E 启动改为等待 `http://127.0.0.1:5173/api/health`（页面和 API 都就绪）；空响应给出可读错误；刷新同一会话时保留失败提示；失败用例同时断言消息状态。
